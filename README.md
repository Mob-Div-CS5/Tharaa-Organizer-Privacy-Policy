# Tharaa Organizer — Privacy Policy

The privacy policy for the **Tharaa Organizer** app (iOS and Android,
`com.tharaa.organizer`), served as a single self-contained page.

Published with GitHub Pages from `main` / root:

- <https://mob-div-cs5.github.io/Tharaa-Organizer-Privacy-Policy/>

This URL is referenced from App Store Connect and Google Play Console. Both stores
re-check it on every submission, so it must stay reachable and must not require a
sign-in.

## Editing

`index.html` is generated from the markdown sources kept with the app repository
(`store/privacy-policy/privacy-policy-en.md` and `-ar.md`). Edit those and
regenerate rather than hand-editing the HTML, so the two languages stay in step.

Update the "Last updated" date whenever the wording changes materially.
